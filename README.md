# 📊 Ecom Dashboard — Claude Design

**Live site:** https://mayanksewatkar.github.io/ecom-dashboard/

A clean, modern analytics dashboard for e-commerce stores. Built with vanilla HTML, CSS, and JavaScript using Chart.js for data visualisation.

## Features

- **KPI Cards** — Total revenue, orders this week, average order value, and conversion rate with trend badges
- **Revenue Line Chart** — 30-day daily revenue trend powered by Chart.js
- **Top Products** — Ranked by revenue with animated progress bars
- **Recent Orders Table** — Latest transactions with customer avatars and status badges
- **Sidebar Navigation** — Fixed sidebar with active state

## Tech Stack

- HTML5 / CSS3 / Vanilla JS
- [Chart.js](https://www.chartjs.org/) via CDN
- Google Fonts (Inter)
- No build tools or dependencies required

## Getting Started

Open directly in a browser:

```bash
open index.html
```

Or serve locally:

```bash
npx serve .
```
